# Data Dictionary

| Field | Description | Data Type | Analytical Use |
|---|---|---|---|
| EmployeeNumber | Unique employee identifier | Whole number | Distinct employee count |
| Attrition | Whether the employee left | Text | Main outcome |
| Age | Employee age | Whole number | Demographic analysis |
| Gender | Employee gender | Text | Workforce segmentation |
| Department | Employee department | Text | Department analysis |
| JobRole | Employee job role | Text | Role-level analysis |
| JobLevel | Organisational job level | Whole number | Seniority analysis |
| MonthlyIncome | Monthly employee income | Whole number | Compensation analysis |
| OverTime | Whether employee works overtime | Text | Retention-driver analysis |
| YearsAtCompany | Company tenure | Whole number | Tenure analysis |
| YearsSinceLastPromotion | Promotion gap | Whole number | Career development analysis |
| JobSatisfaction | Satisfaction score from 1 to 4 | Whole number | Employee experience analysis |
| WorkLifeBalance | Work-life balance score from 1 to 4 | Whole number | Retention-driver analysis |
| BusinessTravel | Travel frequency | Text | Travel related attrition |
| TotalWorkingYears | Total career experience | Whole number | Experience analysis |
